# Ferrari vs Mercedes Stock Risk Analysis 🚗📉

An interactive **Streamlit dashboard** that compares the **risk and volatility** of **Ferrari (RACE)** and **Mercedes-Benz (MBG.DE)** using real-time stock data.

---

## 💡 Features

- 📥 Pulls live stock data from Yahoo Finance  
- 📊 Calculates **daily returns**, **VaR (Value at Risk)** at 95% and 99% confidence  
- ⚠️ Compares **volatility** of both stocks  
- 📈 Visualizes histograms with VaR lines  
- 🖥️ Interactive sidebar to customize **date range**
